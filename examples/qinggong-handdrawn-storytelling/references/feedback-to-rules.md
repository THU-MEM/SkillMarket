# 反馈转化为可复用规则

以下只整理本任务的创作反馈，不包含私人会话、身份档案或运行配置。

| 反馈 | 应用规则 | 如何检查 |
|---|---|---|
| 像PPT，一页页往下翻 | 同一画布持续增画、对象保持身份，章节不是清屏指令 | 连续查看相邻时刻而非只看每章末帧 |
| 文字多，没有时间看 | 正文放旁白，画面只留短词/数字/图形关系 | 无须暂停也能抓住要点 |
| 字体像普通排版 | 合法手绘字体转SVG路径；诚实区分轮廓描绘与笔顺 | 缺字、字号、描线顺序 |
| 左上标题与logo重叠 | 标识与标题独立安全区 | 检查运动极值，不只看静止 |
| 开头结尾要与参考一致 | 先单独研究首尾结构，再换主题字段 | 对照布局、顺序、停顿与原资产 |
| 有原卡，不应缺席 | 按知识点身份核对原概念/应用卡配对 | 不用旧文件夹编号猜主题 |
| 太慢、太线性 | 快起笔、交叠动作、短重点停顿；不全局加速音频 | 看动作间隔和整段播放 |
| XML带语气 | 按提问/解释/提醒/收束组织SSML，能力逐声线核对 | XML与实际WAV哈希绑定 |
| 卡牌出入要3D | 透视、rotateY/X、z位移、卡边、回稳 | 侧视与关键帧，不能只放大 |
| 鞭梢看着没动 | 改实际末端坐标，让相位向梢端传播 | 记录tip轨迹和极值；清除dash遮挡 |
| 加轻音乐，不影响听感 | 音乐频段避让+电平自动化，少量动作音效 | 最终音轨相对电平、削波与试听分开 |
| 小人形态单一 | 同一设计语言，多表情、手势、站姿，哭笑均有 | 12个独立SVG逐一检查 |
| 角色中间冒一两句 | 店主/工厂只在因果节点插短话，动作与声线绑定 | 不覆盖旁白、不把角色喊话做成高峰爆音 |
| 开场音乐+轻中国风 | 开头短音乐段，正文柔和器乐；重新找合法真实素材 | 音乐风格以素材内容/来源核实，不能改文件名冒充 |

最后两项是后续可选扩展需求；发布此技能并不宣称该多人Qwen换声版本已交付。
