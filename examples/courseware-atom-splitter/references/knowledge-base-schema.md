# 知识基座（Excel 2.0）八表结构说明

本文件描述由 `scripts/build_knowledge_base.py` 生成的八表教学知识基座结构。它把"原子知识点 + 具体项目"的扁平拆分结果，升级为**课件证据—原子内容—知识关系—案例项目—双轨评价—学习证据**一体化网络。

升级原则：**原始拆分归档完整保留，不覆盖；新增表通过稳定 ID 与归档扩展。** 所有 AI 生成的判断（知识类型、认知标签、关系、案例、习题）均为"候选"，需教师用审核状态列确认。

---

## 一、八张工作表

| # | 工作表 | 角色 | 关键 ID |
|---|---|---|---|
| 1 | 原始拆分归档 | 上一版全部原子记录（含15列），可追溯底稿 | — |
| 2 | 原子知识点 | 知识网络主表，每知识节点一行 | 知识点ID（KP-001…） |
| 3 | 知识关系 | 节点间前置/组成/对比/应用等关系 | 关系ID（KR-001…） |
| 4 | 案例与项目 | 独立案例/项目资产，含 PBL 四步 | 资产ID（CA-/PJ-…） |
| 5 | 案例知识映射 | 资产↔知识点的多对多映射 | — |
| 6 | 教学评价 | 每节点双轨评价（无AI轨/有AI轨） | 评价ID（EV-001…） |
| 7 | 审核与学习证据 | 教师审核 + 学生验证动态记录 | 审核ID（RV-001…） |
| 8 | 填写说明 | 全部规则与枚举 | — |

## 二、字段定义（核心表）

### 原子知识点（21列）
`知识点ID, 课程, 章节, 知识点名称, 知识类型, 一句话定义, 原概念解释, 核心机制, 适用边界, 非适用条件, 常见误区, 前置知识, 迁移场景, 认知价值标签, 候选理由, 课件来源, 章节及页码, 原文证据摘录, 内容状态, 审核状态, 版本`

- **知识类型**（单选，下拉枚举）：概念 / 原理·机制 / 模型·框架 / 方法·流程 / 判断准则 / 事实·背景。
- **认知价值标签**（可多选）：核心知识 / 门槛知识候选 / 纽结知识候选 / 同构知识候选 / 普通支撑知识。
- **原文证据摘录**：优先保存 文件名 + PDF页码 + 原文片段；无法定位时写"待人工补录课件原文摘录"。
- **审核状态**（下拉枚举）：AI候选 / 待教师确认 / 教师已确认 / 需要修订。

### 知识关系（9列）
`关系ID, 源知识点ID, 源知识点, 关系类型, 目标知识点ID, 目标知识点, 关系依据, 成立条件, 审核状态`

- **关系类型**（下拉枚举）：前置 / 组成 / 因果 / 对比 / 应用 / 同构。
- 自动生成三类关系：①同章顺序→前置；②配置中的组成关系；③配置中的对比/应用关系对。

### 案例与项目（16列）
`资产ID, 资产类型, 名称, 分类, 完整案例或项目描述, 来源层级, 来源文件, 章节及页码, 发现, 学习, 研制, 反思, 能力目标, 高阶认知目标, 审核状态, 版本`

- **来源层级**（下拉枚举）：课件案例线索+AI扩写 / AI虚构教学案例 / 待人工判定。
- **发现/学习/研制/反思**：项目按 PBL 四步循环组织；纯案例资产此项为"不适用"。

### 案例知识映射（6列）
`资产ID, 知识点ID, 知识点名称, 映射角色, 观察位置或调用说明, 审核状态`
- 支持一个资产映射多个知识点，并说明每个知识点在资产中的观察/调用位置。

### 教学评价（12列）
`评价ID, 知识点ID, 知识点名称, 原习题1, 原习题2, 习题1_无AI轨, 习题2_有AI轨, 评分标准, 过程证据, 能力目标, 内容状态, 版本`
- **无AI轨**：检验学生独立解释机制、辨析边界、引用证据与判断的能力。
- **有AI轨**：要求提交 AI 原答、提示词、错误审查、修订记录与最终判断，检验人机协同控制力。

### 审核与学习证据（13列）
`审核ID, 知识点ID, 知识点名称, AI候选状态, 教师审核状态, 学生验证状态, 教师判断理由, 学生卡点证据, 学生顿悟证据, AI常见错误, 审核人及日期, 版本, 修改记录`
- 教师仅需在"教师审核状态/判断理由/修改记录"等列操作；其余 AI 待确认。

## 三、来源层级与标注纪律

| 来源层级 | 含义 | 标注 |
|---|---|---|
| 课件原文 | 直接复制课件原文且可定位页码 | 不得改写后仍标原文 |
| 课件案例线索+AI扩写 | 课件给线索，正文 AI 补写 | 文末【来源：文件；章节页码】 |
| 外部真实案例 | 含可核验出处 | 注明作者/机构/链接 |
| AI虚构教学案例 | 为教学目的虚构 | 文末【AI生成】，不得当事实 |

## 四、领域配置（references/*-kb-config.json）

课程专属规则全部外置为配置，换课程只需替换该 JSON：

- `course` / `version` / `highlighter`（主题色，默认清华紫 #660874）
- `kb_id_prefixes`：各表 ID 前缀
- `pdf_pages`：PDF文件名 → 转录本（pages json）文件名，用于原文证据回填；缺失则降级为"待人工补录"
- `knowledge_type_keywords`：知识类型分类关键词
- `cognitive_tags`：核心/门槛/纽结/同构四类认知标签词表
- `component_relations`：组成关系（父→子列表）
- `contrast_relations` / `application_relations`：对比对 / 应用对
- `expected_counts`：原始归档与知识点期望数量（供校验）
