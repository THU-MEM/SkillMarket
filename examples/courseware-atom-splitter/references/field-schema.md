# 课件原子知识点拆分 — 字段与规则（权威说明）

> 本文件是 `courseware-atom-splitter` 技能的权威规则文档，与 `references/field-schema.json`
> 一一对应。JSON 供脚本机器读取，本文档供执行前/执行中理解规则。

## 一、目标产物

将若干课程课件（PDF/PPT）拆分为可独立统计、检索、复用的原子单元，并沉淀为
**两页标准化 Excel**：

- **拆分结果**（主表）：逐行记录一个原子知识点或具体项目。
- **填写说明**（规范页）：只写拆分标准、字段定义、分类规则、待补充规则、案例/习题生成规则。

最终通过 `tencent-docs` 技能发布为**腾讯共享 Excel**，用于线上教育平台知识基座。

## 二、两条记录 Schema

### 2.1 原子知识点（条目类型 = 知识点）

| 字段 | 规则 |
|---|---|
| 主标题 | 统一填写课程名（配置 `main_title`，如“战略管理”） |
| 二级标题 | 所属课程模块 |
| 三级标题 | 原子概念名称 |
| 概念定义 | 一句话边界定义 |
| 概念解释 | 概念逻辑/适用含义 |
| 对应案例 | 完整案例（含主体/冲突/结果/映射），标来源或【AI生成】 |
| 对应习题1 / 习题2 | 由 AI 生成互补习题，均标【AI生成】 |
| 课件来源 | 原始课件文件名（可多来源） |
| 所在章节及页码 | 模块/章节 + 页码或页码范围 |
| 老师认定盖戳 | **必须留空** |
| 一级标题 / 项目分类 / 对应知识点 / 概念定义(项目行) | 填“不适用” |

### 2.2 具体项目（条目类型 = 具体项目）

| 字段 | 规则 |
|---|---|
| 一级标题 | 项目所属一级主题 |
| 二级标题 | 项目名称 |
| 项目分类 | 见下方分类枚举 |
| 对应知识点 | 关联知识点（多者用中文分号分隔） |
| 概念解释 | 项目任务/案例内容说明 |
| 对应案例 / 对应习题1 / 习题2 | 同知识点行规则 |
| 课件来源 / 所在章节及页码 | 同知识点行规则 |
| 老师认定盖戳 | **必须留空** |
| 主标题 / 三级标题 / 概念定义 | 填“不适用” |

### 2.3 列顺序（拆分结果页 15 列）

```

概念定义, 概念解释, 对应案例, 对应习题1, 对应习题2, 课件来源,
所在章节及页码, 老师认定盖戳
```

### 2.4 项目分类枚举

模型应用 / 课堂讨论 / 课堂项目 / 小组作业 / 个人作业

## 三、拆分标准

1. **原子性**：每行只记录一个可独立理解、统计、检索、复用的知识点或项目，不合并并列概念。
2. **最小完整语义**：知识点须有独立名称+定义+解释；项目须有独立名称+分类+关联知识点+内容说明。
3. **颗粒度一致**：同层条目抽象程度相近；模型、模型维度、战略类型、案例、作业分别成条。
4. **证据约束**：仅依据课件中明确出现的定义、框架、案例、习题、任务拆分，不补写课件没有的结论。
5. **来源追溯**：每条保留课件文件名+章节/页码；多份课件重复的同一知识点合并为一条并标多来源。
6. **去重规则**：名称与定义、适用范围一致的合并；同一概念的维度/阶段/类型具独立语义时分别保留。
7. **排除范围**：课程方式、教师联系方式、纯封面、致谢、无实质内容的装饰页不拆。

## 四、字段定义要点

- **概念定义**：知识点的一句话边界定义；项目行填“不适用”。
- **概念解释**：说明概念逻辑/适用含义，或说明项目任务/案例内容。
- **对应案例**：完整教学案例，四要素齐备（主体/情境 → 关键决策或冲突 → 结果或影响 → 知识点映射）。
- **对应习题1/2**：教学可用习题；AI 生成两道互补题，习题1偏概念辨析/简答，习题2偏综合应用/案例分析，均标【AI生成】。
- **课件来源**：原始课件文件名；跨课件重复内容合并后同时列出多份来源。
- **所在章节及页码**：模块/章节名称 + 页码或页码范围，便于回溯。
- **老师认定盖戳**：教师审核确认列，初始必须留空。

## 五、分类规则

- 案例类（企业/失败/行业/制度/背景案例）：按研究对象与用途分类；失败案例强调战略失误或优势失效，背景案例用于引入分析。
- 活动类（模型应用/课堂讨论/课堂项目/小组作业/个人作业）：模型应用指用框架完成分析；其余按课件明确教学活动形式分类。

## 六、待补充规则

- **使用条件**：课件未提供对应案例/习题/必要信息时填“待补充”，不得依常识或外部资料推断。
- **与不适用的区别**：“待补充”= 该字段原则上可填但课件缺失；“不适用”= 该字段不属于当前条目类型。
- **后续补录**：保留原始来源；新增外部材料另行标注来源并经教师认定。

## 七、案例与习题生成规则（AI 辅助）

- **来源标注**：基于课件已有案例线索扩写 → 文末标【来源：课件文件名；章节及页码】；
  课件未提供明确案例 → AI 生成教学示例并标【AI生成】，仅供教学，须教师认定后方可作正式案例。
- **习题生成**：习题1侧重概念辨析/定义边界/判断标准；习题2侧重情境应用/方案比较/决策建议；均标【AI生成】，不替代教师原创。
- **质量要求**：案例须为完整段落而非一句话；习题须给背景、任务要求与作答方向，避免空泛。

## 八、格式与样式（发布为 Excel 时建议）

- 表头：背景 `#660874`、字色 `#FFFFFF`、加粗、水平/垂直居中。
- 数据区：白底深色字、自动换行、垂直顶端对齐。
- 冻结首行、开启自动筛选、所有单元格细浅灰边框。
- 不增加用户未要求的图表/透视表/公式/额外工作表。
- 仅“老师认定盖戳”列真正留空；“待补充”保持为文本，不擅自填充。
